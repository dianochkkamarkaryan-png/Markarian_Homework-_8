# В VK WorkSpace появилась корзина для удалённых пользователей

*11 ноября 2026*

Удаление учётной записи в VK WorkSpace 26.3 стало обратимым. Если пользователя удалили по ошибке, администратор вернёт его вместе с данными. Заводить учётную запись заново и собирать информацию по частям не придётся.

В панели администрирования появился раздел «Корзина». Удалённые учётные записи попадают туда и не исчезают сразу. В разделе работает поиск: можно выбрать несколько пользователей и восстановить их или удалить окончательно. Администратор сам решает, кого вернуть, а кого убрать навсегда. Пока пользователь находится в корзине, его данные остаются во всех сервисах. После окончательного удаления они стираются везде.

В корзину попадают и пользователи, удалённые при импорте из CSV. Удаление через интеграцию с AD корзина не учитывает. Срок хранения задаётся в конфигурации, размер корзины не ограничен. Перенос, восстановление и окончательное удаление записываются в журнал аудита.

Администраторам стоит заранее выбрать срок хранения пользователей в корзине, сверить его с правилами компании по хранению данных и рассказать об изменении коллегам. Подробности есть в описании релиза 26.3.
